# ИИ-монтаж из своих исходников

Сначала прочитайте скилл `hyperframes`; для аудио — `media-use`, для команд — `hyperframes-cli`. Остальные скиллы выбирайте по задаче. Это дополнение к официальным скиллам, не их замена.

## Инструменты

Рабочая обёртка находится рядом с этим файлом: `scripts/hf.mjs`. Вызывайте её через Node.js с абсолютным путём; текущий каталог — редактируемый HyperFrames-проект. Например `node <skill-dir>/scripts/hf.mjs check --json`. Обёртка использует пути из `~/.ai-video-editing/runtime-info.json` (или `$AI_VIDEO_HOME`). Если конфигурации нет, прочитайте README https://github.com/umbrel-la/ai-video-editing-skills и выполните установку по явному запросу пользователя. Не переустанавливайте исправные инструменты ради демонстрации.

## Работа с исходниками

- Найдите медиа в корне указанной папки и существующих подпапках; не предполагайте наличие папки «Исходники».
- Составьте список файлов, длительностей и назначения звуковых дорожек. Оригиналы не меняйте; монтажные ассеты сохраняйте в отдельном проекте.
- При отдельном микрофоне синхронизируйте его с камерой по звуку и используйте как основной голос. Проверяйте дрейф в конце записи. Не складывайте два одинаковых голоса.
- Используйте фактически записанные реплики. Убирайте неудачные дубли и лишние паузы, сохраняя естественный темп. Не добавляйте придуманные фразы и не синтезируйте голос без запроса.
- Отдельная запись «дополнение» заменяет только указанные пользователем места, не весь основной файл. Не считайте, что любое новое аудио содержит только одно слово: проверяйте его заново.

## Монтаж и сдача

- Длительность, формат и стиль берите из задания; никакого обязательного 60-секундного шаблона. Если речи больше доступного времени, предложите конкретное сокращение текста, не ускоряйте молча.
- Для вертикального ролика интерфейс приближайте к действию, а подписи проверяйте в размере телефона. Субтитры должны соответствовать речи и не закрывать лицо или важную кнопку.
- Недостающие записи обозначайте явно только если пользователь согласен на черновик. Контакты, QR-коды и обещания не выдумывайте.
- При переходе с камеры на новую закадровую запись завершайте видимую речь до смены голоса; не оставляйте несинхронно двигающиеся губы. Анимацию набора/отправки сообщения привязывайте к словам.
- Перед финалом запустите HyperFrames check, просмотрите кадры изменённых мест, экспортируйте и проверьте MP4: размер, длительность, звук, стыки, последнюю фразу. Отмечайте, если звук проверен только метриками/распознаванием, а не прослушан.
- Откройте устойчивый фоновый preview через `preview --background`, отдайте MP4 и редактируемый проект. Сохраните STATE.md с актуальными путями, версией, принятыми решениями и недостающими материалами. Предыдущую полезную версию сохраните.
