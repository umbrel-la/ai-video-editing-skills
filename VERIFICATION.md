# Что проверено

Проверено 10 ноября 2026 на Windows x64, Node.js 24.13.0, HyperFrames 0.9.30 и существующих FFmpeg/ffprobe 9.0.2.

- Все 313 файлов девяти официальных скиллов сверены по Git blob SHA-1 с публичным деревом heygen-com/hyperframes на коммите, указанном в UPSTREAM.json.
- Сравнение с локальными личными исходниками автора не нашло совпадений. В Git не включены видео, озвучка, кадры, QR-коды и проект авторского ролика. MP3 внутри `media-use/audio/assets/sfx` — только стандартные эффекты публичного upstream, их хеши также проверены.
- Установка десяти скиллов в отдельный тестовый каталог выполнена. Повторный запуск сохраняет существующие папки. Системные инструменты использованы повторно.
- Два автоматических теста установщика проходят: сохранение пользовательского скилла при наличии новой версии, повторная установка без замены и корректное обнаружение отсутствующего исполняемого файла. Тестовый путь содержит кириллицу и пробел.
- `skills add . --list` обнаруживает все десять скиллов.
- Проверка HyperFrames и настоящий локальный рендер синтетического ролика прошли: MP4, 360×640, 30 fps, 2 секунды. В тесте нет частных материалов и аудиодорожки; звук и распознавание речи этим тестом не проверяются. Предупреждение об отсутствии GSAP-таймлайна в намеренно статичном тесте допустимо.
- Локальные отчёты, пути пользователя, тестовые установки и сам тестовый MP4 исключены из Git.

Не утверждается, что проверена установка на чистую ОС: на этой машине инструменты уже были. Ветки скачивания недостающих пакетов, macOS, Linux, альтернативные архитектуры и платные сервисы здесь не прогонялись. GitHub Actions не настроен: подключение издателя не имеет права workflow. Для проверки доступны локальные `npm test`, `node scripts/verify-bundle.mjs` и настоящий видео-рендер `node scripts/smoke.mjs`.
