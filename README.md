# ИИ-монтаж: HyperFrames + FFmpeg для Codex

Набор скиллов и установщик для монтажа видео через чат: записи камеры и экрана, голос, субтитры, приближения интерфейса и motion-графика. На выходе — MP4 и редактируемый HyperFrames-проект.

**В репозитории нет личных видео, голосовых записей, скриншотов и исходников автора.** Есть инструкции, скрипты и публичные демонстрационные ресурсы официальных скиллов HyperFrames. Готовый авторский ролик сюда не включён.

## Самый простой способ: отправьте это в Codex

Нужен Codex с доступом к локальным файлам и терминалу на компьютере. Обычный чат без выполнения команд установить программы не сможет.

Скопируйте сообщение целиком:

```text
Установи мне набор для ИИ-монтажа:
https://github.com/umbrel-la/ai-video-editing-skills

Прочитай README.md и AGENTS.md. Скачай репозиторий в постоянную
отдельную папку, не внутрь моих исходников. Проверь Node.js >=22
и npm; если их нет, установи Node.js LTS из официального источника.
Используй существующие исправные установки.

Выполни node scripts/setup.mjs, затем node scripts/smoke.mjs.
Существующие скиллы и мои настройки не перезаписывай.
Проверь, что тестовый MP4 действительно создан, и покажи путь к нему.
Если что-то не установилось, назови конкретную ошибку.
После установки объясни, как дать тебе папку с исходниками для монтажа.
```

**Что происходит:** Codex читает инструкцию, запускает установщик, устанавливает недостающие инструменты и рендерит короткий тест. Одна ссылка сама по себе ничего не запускает. На новом компьютере установка зависит от доступа к интернету и разрешений системы; вход в платный сервис или действия администратора могут потребовать вашего участия.

## Что устанавливается

| Компонент | Назначение |
| --- | --- |
| 9 официальных скиллов HyperFrames | Монтаж, анимация, субтитры, работа с медиа, проверка и рендер |
| `ai-video-editing` | Практический процесс монтажа из камеры, экрана и отдельного микрофона |
| HyperFrames CLI | Просмотр в браузере, проверка проекта, экспорт MP4 |
| FFmpeg и ffprobe | Обработка и анализ видео/аудио |

Скиллы: `hyperframes`, `hyperframes-cli`, `hyperframes-registry`, `media-use`, `reverse-any-video`, `style-sampling`, `figma`, `slideshow`, `remotion-to-hyperframes`, `ai-video-editing`.

Набор **не устанавливает Codex**, не оформляет подписки и не входит в ваши аккаунты. Для тестового ролика не нужны ключи API или авторизация HeyGen. Генерация новых изображений/голоса, некоторые модели и функции HyperFrames могут потребовать отдельного аккаунта, тарифа или кредитов. Копирование скиллов не открывает платные функции.

## Если устанавливаете вручную

Сначала установите [Node.js LTS](https://nodejs.org/) версии **22 или новее** вместе с npm. Git нужен только для команды `git clone`: вместо неё можно скачать **Code → Download ZIP** и распаковать архив.

```bash
git clone https://github.com/umbrel-la/ai-video-editing-skills.git
cd ai-video-editing-skills
node scripts/setup.mjs
node scripts/smoke.mjs
```

Тестовый ролик появится здесь:

```text
ai-video-editing-skills/smoke-output/ready.mp4
```

Не удаляйте папку набора, если пользуетесь её командами и тестом. Сами установленные скиллы и инструменты сохраняются отдельно.

### Куда устанавливаются файлы

- Скиллы: `~/.agents/skills/` — пользовательские скиллы, доступные из разных проектов.
- Недостающий runtime: `~/.ai-video-editing/runtime/`.
- Пути к инструментам: `~/.ai-video-editing/runtime-info.json`.
- Отчёт конкретной установки: `setup-report.json` в папке набора; он не попадает в Git.

`~` — ваша домашняя папка. Установщик не меняет системный PATH и не требует глобального npm install. Уже работающие HyperFrames, FFmpeg и ffprobe используются повторно. Существующие папки скиллов остаются без изменений: смотрите список `preserved` в отчёте. При необходимости сравните версии отдельно — установщик не обещает, что ваш сохранённый старый скилл совпадает с набором.

Если новый скилл не появился на следующем сообщении, перезапустите Codex. Каталоги скиллов описаны в [официальной документации](https://learn.chatgpt.com/docs/build-skills).

### Только скиллы, без программ

Из скачанной папки:

```bash
node scripts/setup.mjs --skip-tools
```

Или через совместимый CLI skills:

```bash
npx skills add umbrel-la/ai-video-editing-skills --skill '*' --agent codex --global --yes
```

Эта команда ставит **только скиллы**. Для готовности HyperFrames и FFmpeg выполните полный установщик из раздела выше. Команда использует [skills от Vercel](https://github.com/vercel-labs/skills).

## Первый монтаж

1. Создайте отдельную папку проекта.
2. Скопируйте туда свои видео камеры, записи экрана и озвучку. Можно прямо в корень; подпапка «Исходники» не обязательна.
3. Откройте эту папку в Codex.
4. Отправьте задачу, например:

```text
Используй скилл ai-video-editing и HyperFrames.
Проанализируй медиа в этой папке и подпапках. Оригиналы не меняй.
Камера — моё лицо, запись экрана — демонстрация действий,
отдельный микрофон — основной голос: синхронизируй его с камерой.

Собери вертикальный ролик 9:16 примерно на 60 секунд.
Убери неудачные дубли и лишние паузы, сохрани естественный темп речи.
Добавь точные субтитры, аккуратную motion-графику и приближения
интерфейса, чтобы действия читались с телефона.
Не выдумывай речь и недостающие кадры.

Открой результат в браузере, сохрани проверочный MP4,
редактируемый проект и STATE.md с текущими путями и состоянием.
```

Длительность, стиль и структуру меняйте под свой ролик. Монтаж требует самих исходников и задания; установленный набор не создаёт персональный ролик из пустой папки.

## Проверка и команды

```bash
# Проверить установку без изменений и скачивания
node scripts/setup.mjs --check

# Проверить сам установщик
npm test

# В папке набора: справка по HyperFrames через настроенный runtime
node scripts/hf.mjs --help
```

Для работы с конкретным проектом запускайте обёртку **из папки этого проекта**, указав абсолютный путь к `scripts/hf.mjs` из набора:

```text
node <путь-к-набору>/scripts/hf.mjs check --json
node <путь-к-набору>/scripts/hf.mjs preview --background
node <путь-к-набору>/scripts/hf.mjs render --quality looks -o result.mp4
```

Путь с пробелами заключайте в кавычки. Такая же обёртка входит в установленный скилл `ai-video-editing/scripts/hf.mjs`. Она передаёт HyperFrames точные пути к FFmpeg и ffprobe.

## Если что-то не работает

- **`node` не найден / слишком старый:** установите Node.js LTS >=22 и откройте терминал заново.
- **Ошибка npm или загрузки:** проверьте интернет, доступ к npm и GitHub. Не считайте установку завершённой до успешного теста.
- **FFmpeg не запускается на вашей архитектуре:** установите сборку для своей ОС с [официальной страницы FFmpeg](https://ffmpeg.org/download.html), откройте терминал заново и повторите setup. Автозагрузка использует `ffmpeg-static@5.3.0` и `ffprobe-static@3.1.0`; поддержка архитектур определяется этими пакетами.
- **Нужен браузер для рендера:** HyperFrames подготавливает поддерживаемый браузер при первом запуске; загрузка может занять время. На минимальном Linux могут потребоваться системные библиотеки и участие администратора — сохраните точную ошибку.
- **Скилл уже существует:** он сохранён, а не заменён. Проверьте `preserved` в `setup-report.json`.
- **HeyGen просит войти / не хватает кредитов:** это отдельный аккаунт или платная возможность, не ошибка копирования скиллов. Установщик не оплачивает услуги.

Поддержка установки рассчитана на Windows, macOS и Linux с Node.js >=22; фактически проверенную среду и ограничения смотрите в [VERIFICATION.md](VERIFICATION.md).
